🕸️ Graphs

Modeling relationships and connections

What is a Graph?

A graph is a collection of nodes (vertices) connected by edges. Graphs can represent networks, relationships, paths, and many real-world structures.

Graph Representations

// Adjacency List (most common)
class Graph {
    constructor() {
        this.adjacencyList = {};
    }
    
    addVertex(vertex) {
        if (!this.adjacencyList[vertex]) {
            this.adjacencyList[vertex] = [];
        }
    }
    
    addEdge(v1, v2) {
        this.adjacencyList[v1].push(v2);
        this.adjacencyList[v2].push(v1); // For undirected
    }
    
    // Depth First Search
    dfs(start) {
        const result = [];
        const visited = {};
        
        const dfsHelper = (vertex) => {
            visited[vertex] = true;
            result.push(vertex);
            
            for (let neighbor of this.adjacencyList[vertex]) {
                if (!visited[neighbor]) {
                    dfsHelper(neighbor);
                }
            }
        };
        
        dfsHelper(start);
        return result;
    }
    
    // Breadth First Search
    bfs(start) {
        const queue = [start];
        const result = [];
        const visited = {};
        visited[start] = true;
        
        while (queue.length) {
            const vertex = queue.shift();
            result.push(vertex);
            
            for (let neighbor of this.adjacencyList[vertex]) {
                if (!visited[neighbor]) {
                    visited[neighbor] = true;
                    queue.push(neighbor);
                }
            }
        }
        
        return result;
    }
}

How to read this implementation

  • addVertex/addEdge build the adjacency list so every vertex keeps track of its neighbors.
  • dfs uses recursion and a visited map to walk as deep as possible before backtracking.
  • bfs uses a queue to explore level by level, marking nodes as visited to avoid repeats.
  • Both traversals return the visitation order so you can see exactly how the search progresses.

💻 Practice Problems

1. Number of Islands Medium

Count the number of islands in a 2D grid (DFS/BFS application). 

function numIslands(grid) {
    if (!grid || grid.length === 0) return 0;
    
    let count = 0;
    const rows = grid.length;
    const cols = grid[0].length;
    
    function dfs(i, j) {
        if (i < 0 || i >= rows || j < 0 || j >= cols || 
            grid[i][j] === '0') {
            return;
        }
        
        grid[i][j] = '0'; // Mark as visited
        
        // Visit all 4 directions
        dfs(i + 1, j);
        dfs(i - 1, j);
        dfs(i, j + 1);
        dfs(i, j - 1);
    }
    
    for (let i = 0; i < rows; i++) {
        for (let j = 0; j < cols; j++) {
            if (grid[i][j] === '1') {
                count++;
                dfs(i, j);
            }
        }
    }
    
    return count;
}

Why this solution works

  • Every time we see a 1, we start a DFS that "sinks" that island by flipping connected cells to 0.
  • Recursive calls explore all four directions so diagonal cells stay untouched, matching the problem constraints.
  • Counting happens only when we initiate a DFS, guaranteeing each island increments the total exactly once.
  • Mutating the grid doubles as a visited set, which keeps the space usage low.
Time: O(m × n) | Space: O(m × n)

2. Course Schedule (Cycle Detection) Medium

Determine if you can finish all courses given prerequisites (detect cycle in directed graph). 

function canFinish(numCourses, prerequisites) {
    const graph = Array.from({ length: numCourses }, () => []);
    
    // Build adjacency list
    for (let [course, prereq] of prerequisites) {
        graph[prereq].push(course);
    }
    
    const visited = new Array(numCourses).fill(0);
    // 0: unvisited, 1: visiting, 2: visited
    
    function hasCycle(course) {
        if (visited[course] === 1) return true; // Cycle detected
        if (visited[course] === 2) return false; // Already processed
        
        visited[course] = 1; // Mark as visiting
        
        for (let next of graph[course]) {
            if (hasCycle(next)) return true;
        }
        
        visited[course] = 2; // Mark as visited
        return false;
    }
    
    for (let i = 0; i < numCourses; i++) {
        if (hasCycle(i)) return false;
    }
    
    return true;
}

Reading the code

  • The adjacency list points from a prerequisite to the course that depends on it.
  • The visited array uses three states (unvisited, visiting, visited) to detect back edges.
  • If we ever re-enter a node that is currently "visiting", we discovered a cycle and must return false.
  • Processing every node ensures disconnected components are also checked.
Time: O(V + E) | Space: O(V + E)

📚 Key Takeaways

  • DFS uses stack (recursion), BFS uses queue
  • Adjacency list is most space-efficient for sparse graphs
  • Graph algorithms solve connectivity, shortest path, cycle detection
  • Many real-world problems map to graph problems
