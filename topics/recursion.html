🔁 Recursion

Functions calling themselves

What is Recursion?

Recursion is when a function calls itself. Every recursive function needs:

  1. Base case: Condition to stop recursion
  2. Recursive case: Function calls itself with modified input

Examples

// Factorial
function factorial(n) {
    if (n <= 1) return 1; // Base case
    return n * factorial(n - 1); // Recursive case
}

// Fibonacci
function fibonacci(n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2);
}

// Power
function power(base, exp) {
    if (exp === 0) return 1;
    return base * power(base, exp - 1);
}

Spot the pattern

  • Each function guards with a base case that stops the infinite descent.
  • The recursive case shrinks the problem (n-1, exp-1) so we move toward the base quickly.
  • Multiplying the recursive result by the current value mirrors the mathematical recurrence.
  • These simple examples highlight how recursion replaces loops when the state can be expressed as "current work + smaller subproblem".

💻 Practice Problems

1. Generate Parentheses Medium

function generateParenthesis(n) {
    const result = [];
    
    function backtrack(str, open, close) {
        if (str.length === 2 * n) {
            result.push(str);
            return;
        }
        
        if (open < n) {
            backtrack(str + '(', open + 1, close);
        }
        
        if (close < open) {
            backtrack(str + ')', open, close + 1);
        }
    }
    
    backtrack('', 0, 0);
    return result;
}

Backtracking flow

  • We track how many ( and ) we have placed so far.
  • We can always add another ( while open < n.
  • We only add ) when close < open to keep the string valid.
  • When the string reaches length 2 * n, we record a completed combination.

2. Permutations Medium

function permute(nums) {
    const result = [];
    
    function backtrack(current, remaining) {
        if (remaining.length === 0) {
            result.push([...current]);
            return;
        }
        
        for (let i = 0; i < remaining.length; i++) {
            current.push(remaining[i]);
            const newRemaining = remaining.filter((_, idx) => idx !== i);
            backtrack(current, newRemaining);
            current.pop();
        }
    }
    
    backtrack([], nums);
    return result;
}

Exploring the tree

  • current holds the partial permutation; remaining lists unused numbers.
  • At each level we choose one element, append it, and recurse on the rest.
  • After exploring a branch we pop to undo the choice (classic backtracking).
  • When remaining is empty, the partial path is a complete permutation to push into result.
