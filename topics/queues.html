🎫 Queues

First In, First Out (FIFO) Data Structure

What is a Queue?

A queue is a linear data structure that follows the First In, First Out (FIFO) principle. Think of it like a line of people waiting - the first person to join the line is the first to be served.

Key Operations

Enqueue

Add element to the rear - O(1)

Dequeue

Remove element from front - O(1)

Front/Peek

View front element - O(1)

isEmpty

Check if queue is empty - O(1)

Types of Queues

  • Simple Queue: Basic FIFO queue
  • Circular Queue: Last position connects to first (efficient space usage)
  • Priority Queue: Elements served based on priority
  • Deque (Double-ended Queue): Insert/remove from both ends

Real-World Applications

  • Task scheduling in operating systems
  • Print queue management
  • Breadth-First Search (BFS) algorithm
  • Request handling in web servers
  • Customer service lines

Queue Implementation

// Queue class using array
class Queue {
    constructor() {
        this.items = [];
    }
    
    // Add element to rear
    enqueue(element) {
        this.items.push(element);
    }
    
    // Remove and return front element
    dequeue() {
        if (this.isEmpty()) {
            return null;
        }
        return this.items.shift();
    }
    
    // View front element
    front() {
        if (this.isEmpty()) {
            return null;
        }
        return this.items[0];
    }
    
    // Check if queue is empty
    isEmpty() {
        return this.items.length === 0;
    }
    
    // Get queue size
    size() {
        return this.items.length;
    }
    
    // Clear queue
    clear() {
        this.items = [];
    }
    
    // Print queue
    print() {
        return this.items.join(' <- ');
    }
}

// Circular Queue implementation
class CircularQueue {
    constructor(capacity) {
        this.items = new Array(capacity);
        this.capacity = capacity;
        this.front = -1;
        this.rear = -1;
        this.size = 0;
    }
    
    enqueue(element) {
        if (this.isFull()) {
            return false;
        }
        
        if (this.isEmpty()) {
            this.front = 0;
        }
        
        this.rear = (this.rear + 1) % this.capacity;
        this.items[this.rear] = element;
        this.size++;
        return true;
    }
    
    dequeue() {
        if (this.isEmpty()) {
            return null;
        }
        
        const item = this.items[this.front];
        
        if (this.front === this.rear) {
            this.front = -1;
            this.rear = -1;
        } else {
            this.front = (this.front + 1) % this.capacity;
        }
        
        this.size--;
        return item;
    }
    
    isFull() {
        return this.size === this.capacity;
    }
    
    isEmpty() {
        return this.size === 0;
    }
}

Understanding both versions

  • The basic queue wraps a JavaScript array and relies on push/shift to model enqueue/dequeue.
  • front, size, and isEmpty provide the common inspection helpers.
  • The circular queue replaces shifting with two indices that wrap around the fixed-size buffer using modulo arithmetic.
  • Tracking front, rear, and size lets us distinguish between empty and full states without moving data.

💻 Practice Problems

1. Implement Queue using Stacks Easy

Implement a queue using only two stacks. The implemented queue should support all normal queue operations.

Operations:
enqueue(x) - Push element x to back
dequeue() - Remove element from front
peek() - Get front element
empty() - Return whether queue is empty

Solution:

/**
 * Queue using Two Stacks
 * Key insight: Use one stack for enqueue, another for dequeue
 */
class MyQueue {
    constructor() {
        this.stack1 = []; // For enqueue
        this.stack2 = []; // For dequeue
    }
    
    /**
     * Push element to back of queue
     * @param {number} x
     */
    enqueue(x) {
        // Always push to stack1
        this.stack1.push(x);
    }
    
    /**
     * Remove and return front element
     * @return {number}
     */
    dequeue() {
        // If stack2 is empty, transfer from stack1
        if (this.stack2.length === 0) {
            while (this.stack1.length > 0) {
                this.stack2.push(this.stack1.pop());
            }
        }
        
        // Pop from stack2
        return this.stack2.pop();
    }
    
    /**
     * Get front element
     * @return {number}
     */
    peek() {
        // If stack2 is empty, transfer from stack1
        if (this.stack2.length === 0) {
            while (this.stack1.length > 0) {
                this.stack2.push(this.stack1.pop());
            }
        }
        
        // Peek at top of stack2
        return this.stack2[this.stack2.length - 1];
    }
    
    /**
     * Check if queue is empty
     * @return {boolean}
     */
    empty() {
        return this.stack1.length === 0 && this.stack2.length === 0;
    }
}

// Usage
const queue = new MyQueue();
queue.enqueue(1);
queue.enqueue(2);
console.log(queue.peek());      // 1
console.log(queue.dequeue());   // 1
console.log(queue.empty());     // false

Explanation:

Two-stack approach:
1. Stack1: Used for enqueue operations
2. Stack2: Used for dequeue operations
3. When dequeuing and stack2 is empty, transfer all from stack1
4. This reverses the order, making LIFO become FIFO!
5. Amortized O(1) for all operations

Time Complexity: Amortized O(1) for all operations
Space Complexity: O(n) - Two stacks

2. Design Circular Queue Medium

Design a circular queue with fixed size. Support enqueue, dequeue, front, rear, isEmpty, and isFull operations.

Note: A circular queue uses a fixed-size array and wraps around when reaching the end.

Solution:

/**
 * Design Circular Queue
 * Uses modulo arithmetic to wrap around
 */
class MyCircularQueue {
    constructor(k) {
        this.capacity = k;
        this.items = new Array(k);
        this.front = -1;
        this.rear = -1;
        this.size = 0;
    }
    
    /**
     * Insert element at rear
     * @param {number} value
     * @return {boolean}
     */
    enQueue(value) {
        if (this.isFull()) {
            return false;
        }
        
        // If queue is empty, set front to 0
        if (this.isEmpty()) {
            this.front = 0;
        }
        
        // Move rear circularly and add element
        this.rear = (this.rear + 1) % this.capacity;
        this.items[this.rear] = value;
        this.size++;
        
        return true;
    }
    
    /**
     * Delete element from front
     * @return {boolean}
     */
    deQueue() {
        if (this.isEmpty()) {
            return false;
        }
        
        // If only one element, reset pointers
        if (this.front === this.rear) {
            this.front = -1;
            this.rear = -1;
        } else {
            // Move front circularly
            this.front = (this.front + 1) % this.capacity;
        }
        
        this.size--;
        return true;
    }
    
    /**
     * Get front element
     * @return {number}
     */
    Front() {
        if (this.isEmpty()) {
            return -1;
        }
        return this.items[this.front];
    }
    
    /**
     * Get rear element
     * @return {number}
     */
    Rear() {
        if (this.isEmpty()) {
            return -1;
        }
        return this.items[this.rear];
    }
    
    /**
     * Check if queue is empty
     * @return {boolean}
     */
    isEmpty() {
        return this.size === 0;
    }
    
    /**
     * Check if queue is full
     * @return {boolean}
     */
    isFull() {
        return this.size === this.capacity;
    }
}

// Usage
const cQueue = new MyCircularQueue(3);
console.log(cQueue.enQueue(1));  // true
console.log(cQueue.enQueue(2));  // true
console.log(cQueue.enQueue(3));  // true
console.log(cQueue.enQueue(4));  // false (full)
console.log(cQueue.Rear());      // 3
console.log(cQueue.isFull());    // true
console.log(cQueue.deQueue());   // true
console.log(cQueue.enQueue(4));  // true

Explanation:

Circular queue key concepts:
1. Use modulo (%) to wrap indices around
2. Track front and rear pointers
3. When rear reaches end, it wraps to beginning
4. More space-efficient than regular queue
5. All operations are O(1)

Time Complexity: O(1) for all operations
Space Complexity: O(k) - Fixed size array

3. Sliding Window Maximum (Using Deque) Hard

Given an array and a sliding window of size k, find the maximum element in each window as it slides from left to right.

Example:
Input: nums = [1,3,-1,-3,5,3,6,7], k = 3
Output: [3,3,5,5,6,7]

Solution:

/**
 * Sliding Window Maximum using Deque
 * @param {number[]} nums
 * @param {number} k
 * @return {number[]}
 */
function maxSlidingWindow(nums, k) {
    const result = [];
    const deque = []; // Stores indices
    
    for (let i = 0; i < nums.length; i++) {
        // Remove indices outside current window
        while (deque.length > 0 && deque[0] < i - k + 1) {
            deque.shift();
        }
        
        // Remove indices of smaller elements (they won't be max)
        while (deque.length > 0 && nums[deque[deque.length - 1]] < nums[i]) {
            deque.pop();
        }
        
        // Add current index
        deque.push(i);
        
        // Add to result when window is complete
        if (i >= k - 1) {
            result.push(nums[deque[0]]);
        }
    }
    
    return result;
}

// Test cases
console.log(maxSlidingWindow([1,3,-1,-3,5,3,6,7], 3));
// Output: [3,3,5,5,6,7]

console.log(maxSlidingWindow([1], 1));
// Output: [1]

console.log(maxSlidingWindow([1,-1], 1));
// Output: [1,-1]

Explanation:

Deque-based approach for O(n) solution:
1. Deque stores indices in decreasing order of values
2. Front of deque always has index of maximum in current window
3. Remove indices outside window from front
4. Remove indices with smaller values from back (can't be max)
5. Add current index to back

Why it's efficient: Each element is added and removed at most once!

Time Complexity: O(n) - Each element processed once
Space Complexity: O(k) - Deque size

📚 Key Takeaways

  • Queues are perfect for level-order traversal and BFS algorithms
  • Circular queues efficiently utilize space with wrap-around
  • Deques (double-ended queues) provide flexibility for both ends
  • Two stacks can simulate a queue with amortized O(1) operations
  • Priority queues (heaps) extend the queue concept with ordering
  • Queues model real-world scenarios like task scheduling and buffering
