🎯 Greedy Algorithms

Making locally optimal choices

What is a Greedy Algorithm?

Greedy algorithms make the locally optimal choice at each step, hoping to find a global optimum. They don't always work, but when they do, they're often simple and efficient.

When to Use Greedy

  • Problem has optimal substructure
  • Greedy choice property holds
  • No need to reconsider past choices

💻 Practice Problems

1. Jump Game Medium

Can you reach the last index?

function canJump(nums) {
    let maxReach = 0;
    
    for (let i = 0; i < nums.length; i++) {
        if (i > maxReach) return false;
        maxReach = Math.max(maxReach, i + nums[i]);
    }
    
    return true;
}

Greedy insight

  • maxReach tracks the furthest index we can get to so far.
  • If we ever land on an index beyond maxReach, it means previous jumps couldn’t reach it.
  • Updating maxReach with i + nums[i] greedily keeps the best jump length seen.
  • Reaching the end of the loop without failing implies every position was reachable, so the last index is too.

2. Meeting Rooms II Medium

Minimum conference rooms needed.

function minMeetingRooms(intervals) {
    const starts = intervals.map(i => i[0]).sort((a, b) => a - b);
    const ends = intervals.map(i => i[1]).sort((a, b) => a - b);
    
    let rooms = 0, endIdx = 0;
    
    for (let i = 0; i < starts.length; i++) {
        if (starts[i] < ends[endIdx]) {
            rooms++;
        } else {
            endIdx++;
        }
    }
    
    return rooms;
}

Why sorting twice helps

  • We sort start times and end times separately to simulate a sweep line.
  • Whenever a meeting starts before the earliest current meeting ends, we need another room.
  • If the start is >= the earliest end, we free a room by moving the end pointer.
  • The pointer dance is greedy: always reuse the room that frees up first.

📚 Key Takeaways

  • Greedy algorithms are intuitive and efficient
  • Prove correctness before implementation
  • Common in interval scheduling and optimization
