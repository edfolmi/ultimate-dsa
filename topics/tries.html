🌲 Tries (Prefix Trees)

Efficient string storage and retrieval

What is a Trie?

A trie is a tree-like data structure for storing strings. Each path from root to leaf represents a word. Excellent for prefix matching and autocomplete.

Implementation

class TrieNode {
    constructor() {
        this.children = {};
        this.isEndOfWord = false;
    }
}

class Trie {
    constructor() {
        this.root = new TrieNode();
    }
    
    insert(word) {
        let node = this.root;
        
        for (let char of word) {
            if (!node.children[char]) {
                node.children[char] = new TrieNode();
            }
            node = node.children[char];
        }
        
        node.isEndOfWord = true;
    }
    
    search(word) {
        let node = this.root;
        
        for (let char of word) {
            if (!node.children[char]) {
                return false;
            }
            node = node.children[char];
        }
        
        return node.isEndOfWord;
    }
    
    startsWith(prefix) {
        let node = this.root;
        
        for (let char of prefix) {
            if (!node.children[char]) {
                return false;
            }
            node = node.children[char];
        }
        
        return true;
    }
}

// Usage
const trie = new Trie();
trie.insert("apple");
console.log(trie.search("apple"));   // true
console.log(trie.search("app"));     // false
console.log(trie.startsWith("app")); // true

Walking through the code

  • Each TrieNode holds a map of children keyed by character plus a flag for word endings.
  • insert walks character by character, creating nodes as needed, and marks the final node as a word.
  • search follows the same path but only returns true if the final node is flagged as the end of a word.
  • startsWith simply checks that every prefix character exists—it doesn’t require isEndOfWord.

2. Word Search II Hard

Find all words from a dictionary in a 2D board.

function findWords(board, words) {
    // Build trie from words
    const trie = new Trie();
    for (let word of words) {
        trie.insert(word);
    }
    
    const result = new Set();
    const rows = board.length;
    const cols = board[0].length;
    
    function dfs(i, j, node, word) {
        if (i < 0 || i >= rows || j < 0 || j >= cols) return;
        
        const char = board[i][j];
        if (char === '#' || !node.children[char]) return;
        
        node = node.children[char];
        word += char;
        
        if (node.isEndOfWord) {
            result.add(word);
        }
        
        board[i][j] = '#'; // Mark visited
        
        dfs(i + 1, j, node, word);
        dfs(i - 1, j, node, word);
        dfs(i, j + 1, node, word);
        dfs(i, j - 1, node, word);
        
        board[i][j] = char; // Restore
    }
    
    for (let i = 0; i < rows; i++) {
        for (let j = 0; j < cols; j++) {
            dfs(i, j, trie.root, '');
        }
    }
    
    return Array.from(result);
}

Combining trie + DFS

  • We preload all dictionary words into a trie so we can test prefixes efficiently during the search.
  • The DFS starts from every board cell, walking up/down/left/right while staying aligned with a trie path.
  • Marking cells with # prevents revisiting them in the current path (backtracking restores them afterward).
  • Whenever we reach a trie node with isEndOfWord, we add the accumulated word to the result set.

📚 Key Takeaways

  • Tries excel at prefix-based operations
  • Used in autocomplete, spell checkers, IP routing
  • Trade space for time - fast lookups
  • All operations are O(m) where m is string length
