📚 Stacks

Last In, First Out (LIFO) Data Structure

What is a Stack?

A stack is a linear data structure that follows the Last In, First Out (LIFO) principle. Think of it like a stack of plates - you can only add or remove plates from the top.

Key Operations

Push

Add element to the top - O(1)

Pop

Remove element from the top - O(1)

Peek/Top

View top element without removing - O(1)

isEmpty

Check if stack is empty - O(1)

Real-World Applications

  • Function call stack (recursion)
  • Undo/Redo operations in editors
  • Browser history (back button)
  • Expression evaluation and syntax parsing
  • Backtracking algorithms

Stack Implementation

// Stack class using array
class Stack {
    constructor() {
        this.items = [];
    }
    
    // Add element to top
    push(element) {
        this.items.push(element);
    }
    
    // Remove and return top element
    pop() {
        if (this.isEmpty()) {
            return null;
        }
        return this.items.pop();
    }
    
    // View top element
    peek() {
        if (this.isEmpty()) {
            return null;
        }
        return this.items[this.items.length - 1];
    }
    
    // Check if stack is empty
    isEmpty() {
        return this.items.length === 0;
    }
    
    // Get stack size
    size() {
        return this.items.length;
    }
    
    // Clear stack
    clear() {
        this.items = [];
    }
    
    // Print stack
    print() {
        return this.items.join(' <- ');
    }
}

How the stack behaves

  • The internal array stores elements with the top at the end, making push/pop O(1).
  • peek and isEmpty give constant-time visibility into the top element and size.
  • size and clear are convenience helpers for diagnostics.
  • print visualizes the stack from bottom to top, which is useful when debugging.

💻 Practice Problems

1. Valid Parentheses Easy

Given a string containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid. An input string is valid if brackets are closed in the correct order.

Examples:
Input: "()" → Output: true
Input: "()[]{}" → Output: true
Input: "(]" → Output: false
Input: "([)]" → Output: false

Solution:

/**
 * Valid Parentheses - Using Stack
 * @param {string} s - String containing brackets
 * @return {boolean} - True if valid, false otherwise
 */
function isValid(s) {
    const stack = [];
    const pairs = {
        ')': '(',
        '}': '{',
        ']': '['
    };
    
    for (let char of s) {
        // If closing bracket
        if (char in pairs) {
            // Check if stack is empty or top doesn't match
            if (stack.length === 0 || stack.pop() !== pairs[char]) {
                return false;
            }
        } else {
            // Opening bracket - push to stack
            stack.push(char);
        }
    }
    
    // Valid only if stack is empty (all brackets matched)
    return stack.length === 0;
}

// Test cases
console.log(isValid("()"));        // true
console.log(isValid("()[]{}"));    // true
console.log(isValid("(]"));        // false
console.log(isValid("([)]"));      // false
console.log(isValid("{[]}"));      // true

Explanation:

1. Use a stack to keep track of opening brackets
2. When encountering opening bracket: push to stack
3. When encountering closing bracket: check if top of stack matches
4. If stack is empty or doesn't match, return false
5. At the end, stack should be empty for valid string

Time Complexity: O(n) - Single pass through string
Space Complexity: O(n) - Stack space in worst case

2. Min Stack Medium

Design a stack that supports push, pop, top, and retrieving the minimum element in constant time.

Operations:
push(val) - Push element onto stack
pop() - Remove element from top
top() - Get top element
getMin() - Retrieve minimum element (O(1))

Solution:

/**
 * MinStack - Stack with O(1) minimum retrieval
 */
class MinStack {
    constructor() {
        this.stack = [];
        this.minStack = []; // Tracks minimum values
    }
    
    /**
     * Push element onto stack
     * @param {number} val
     */
    push(val) {
        this.stack.push(val);
        
        // Update min stack
        if (this.minStack.length === 0 || val <= this.getMin()) {
            this.minStack.push(val);
        }
    }
    
    /**
     * Remove element from top
     */
    pop() {
        if (this.stack.length === 0) return;
        
        const popped = this.stack.pop();
        
        // If popped element was minimum, remove from min stack
        if (popped === this.getMin()) {
            this.minStack.pop();
        }
    }
    
    /**
     * Get top element
     * @return {number}
     */
    top() {
        if (this.stack.length === 0) return null;
        return this.stack[this.stack.length - 1];
    }
    
    /**
     * Get minimum element in O(1)
     * @return {number}
     */
    getMin() {
        if (this.minStack.length === 0) return null;
        return this.minStack[this.minStack.length - 1];
    }
}

// Usage example
const minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
console.log(minStack.getMin());  // -3
minStack.pop();
console.log(minStack.top());     // 0
console.log(minStack.getMin());  // -2

Explanation:

The key insight is using two stacks:
1. Main stack: stores all elements normally
2. Min stack: tracks minimum values
3. When pushing: add to min stack only if it's new minimum
4. When popping: remove from min stack if it was the minimum
5. getMin() just returns top of min stack - O(1)!

Time Complexity: O(1) for all operations
Space Complexity: O(n) - Two stacks

3. Evaluate Reverse Polish Notation Medium

Evaluate the value of an arithmetic expression in Reverse Polish Notation (postfix).

Examples:
Input: ["2","1","+","3","*"] → Output: 9 (i.e., (2 + 1) * 3)
Input: ["4","13","5","/","+"] → Output: 6 (i.e., 4 + (13 / 5))

Solution:

/**
 * Evaluate Reverse Polish Notation
 * @param {string[]} tokens - Array of tokens
 * @return {number} - Result of evaluation
 */
function evalRPN(tokens) {
    const stack = [];
    const operators = {
        '+': (a, b) => a + b,
        '-': (a, b) => a - b,
        '*': (a, b) => a * b,
        '/': (a, b) => Math.trunc(a / b) // Truncate toward zero
    };
    
    for (let token of tokens) {
        if (token in operators) {
            // Pop two operands (note the order!)
            const b = stack.pop();
            const a = stack.pop();
            
            // Apply operator and push result
            const result = operators[token](a, b);
            stack.push(result);
        } else {
            // It's a number, push to stack
            stack.push(parseInt(token));
        }
    }
    
    // Final result is on top of stack
    return stack[0];
}

// Test cases
console.log(evalRPN(["2","1","+","3","*"]));           // 9
console.log(evalRPN(["4","13","5","/","+"]));          // 6
console.log(evalRPN(["10","6","9","3","+","-11","*",
                     "/","*","17","+","5","+"]));      // 22

Explanation:

Reverse Polish Notation (RPN) is perfect for stack-based evaluation:
1. Scan tokens from left to right
2. If token is a number: push to stack
3. If token is operator: pop two operands, apply operator, push result
4. Final result is the only element left in stack

Why it works: In RPN, operators come after operands, so when we encounter an operator, the operands are already on the stack!

Time Complexity: O(n) - Process each token once
Space Complexity: O(n) - Stack space

📚 Key Takeaways

  • Stacks are ideal for problems involving nested structures or backtracking
  • Perfect for bracket matching, expression evaluation, and parsing
  • All basic operations (push, pop, peek) are O(1)
  • Use auxiliary stacks for tracking additional information (like minimum)
  • Function call stack in programming languages is a stack!
  • Consider using stack when you need to reverse order or track previous states
