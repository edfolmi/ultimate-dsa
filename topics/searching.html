Binary Search

// Binary Search - O(log n)
function binarySearch(arr, target) {
    let left = 0;
    let right = arr.length - 1;
    
    while (left <= right) {
        const mid = Math.floor((left + right) / 2);
        
        if (arr[mid] === target) {
            return mid;
        } else if (arr[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    
    return -1; // Not found
}

// Binary Search (Recursive)
function binarySearchRecursive(arr, target, left = 0, right = arr.length - 1) {
    if (left > right) return -1;
    
    const mid = Math.floor((left + right) / 2);
    
    if (arr[mid] === target) return mid;
    if (arr[mid] < target) return binarySearchRecursive(arr, target, mid + 1, right);
    return binarySearchRecursive(arr, target, left, mid - 1);
}

Key observations

  • Because the array is sorted, we can discard half the search space each iteration.
  • Comparing arr[mid] with the target tells us which half could still contain the answer.
  • The recursive variant mirrors the iterative logic but expresses the shrinkage via function calls.
  • Returning -1 when the pointers cross signals that the target does not exist in the array.

💻 Practice Problems

1. Search in Rotated Sorted Array Medium

function search(nums, target) {
    let left = 0, right = nums.length - 1;
    
    while (left <= right) {
        const mid = Math.floor((left + right) / 2);
        
        if (nums[mid] === target) return mid;
        
        // Determine which half is sorted
        if (nums[left] <= nums[mid]) {
            // Left half is sorted
            if (target >= nums[left] && target < nums[mid]) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        } else {
            // Right half is sorted
            if (target > nums[mid] && target <= nums[right]) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
    }
    
    return -1;
}

How the pivot logic works

  • At every step either the left half or the right half is still sorted (because only one rotation happened).
  • We check which half is sorted by comparing the boundary values nums[left] and nums[mid].
  • If the target lies within the sorted half’s range, we search there; otherwise we explore the other half.
  • This keeps the runtime logarithmic even though the array is rotated.

2. Find Peak Element Medium

function findPeakElement(nums) {
    let left = 0, right = nums.length - 1;
    
    while (left < right) {
        const mid = Math.floor((left + right) / 2);
        
        if (nums[mid] > nums[mid + 1]) {
            // Peak is on left side (or mid is peak)
            right = mid;
        } else {
            // Peak is on right side
            left = mid + 1;
        }
    }
    
    return left;
}

Binary search on gradients

  • Comparing nums[mid] with nums[mid + 1] tells us which side has an upward slope.
  • If the slope goes down (nums[mid] > nums[mid+1]), a peak must exist on the left including mid.
  • If the slope goes up, the peak lies to the right; we move left forward.
  • The loop stops when left === right, pinpointing a peak index without scanning linearly.

📚 Key Takeaways

  • Binary search requires sorted data - O(log n) time
  • Modified binary search solves many problems efficiently
  • Think binary search when you see sorted or rotated arrays
