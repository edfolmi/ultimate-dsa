🌳 Trees

Hierarchical data structures for efficient searching and sorting

What is a Tree?

A tree is a hierarchical data structure consisting of nodes connected by edges. Each tree has a root node, and every node has zero or more child nodes. Trees are used to represent hierarchical relationships.

Key Terminology

  • Root: The topmost node
  • Parent/Child: Nodes connected by edges
  • Leaf: Node with no children
  • Height: Longest path from root to leaf
  • Depth: Distance from root to a node
  • Subtree: Tree formed by a node and its descendants

Binary Tree Node

// TreeNode class
class TreeNode {
    constructor(val) {
        this.val = val;
        this.left = null;
        this.right = null;
    }
}

// Binary Search Tree class
class BST {
    constructor() {
        this.root = null;
    }
    
    // Insert value
    insert(val) {
        const newNode = new TreeNode(val);
        
        if (!this.root) {
            this.root = newNode;
            return;
        }
        
        let current = this.root;
        while (true) {
            if (val < current.val) {
                if (!current.left) {
                    current.left = newNode;
                    return;
                }
                current = current.left;
            } else {
                if (!current.right) {
                    current.right = newNode;
                    return;
                }
                current = current.right;
            }
        }
    }
    
    // Search for value
    search(val) {
        let current = this.root;
        
        while (current) {
            if (val === current.val) return true;
            if (val < current.val) {
                current = current.left;
            } else {
                current = current.right;
            }
        }
        
        return false;
    }
}

// Tree Traversals
function inorderTraversal(root) {
    // Left -> Root -> Right
    if (!root) return;
    inorderTraversal(root.left);
    console.log(root.val);
    inorderTraversal(root.right);
}

function preorderTraversal(root) {
    // Root -> Left -> Right
    if (!root) return;
    console.log(root.val);
    preorderTraversal(root.left);
    preorderTraversal(root.right);
}

function postorderTraversal(root) {
    // Left -> Right -> Root
    if (!root) return;
    postorderTraversal(root.left);
    postorderTraversal(root.right);
    console.log(root.val);
}

function levelOrderTraversal(root) {
    // Breadth-first traversal
    if (!root) return;
    
    const queue = [root];
    while (queue.length > 0) {
        const node = queue.shift();
        console.log(node.val);
        
        if (node.left) queue.push(node.left);
        if (node.right) queue.push(node.right);
    }
}

How to interpret this toolkit

  • TreeNode defines the basic structure with left and right child pointers.
  • The BST class inserts values by walking down the tree until it finds the correct null child, preserving the BST invariant.
  • search uses that invariant to skip half of the remaining nodes at every comparison.
  • The traversal helpers show the three DFS orders plus a BFS (level order) that uses a queue.

💻 Practice Problems

1. Maximum Depth of Binary Tree Easy

Find the maximum depth (height) of a binary tree. 

function maxDepth(root) {
    if (!root) return 0;
    
    const leftDepth = maxDepth(root.left);
    const rightDepth = maxDepth(root.right);
    
    return Math.max(leftDepth, rightDepth) + 1;
}

// Iterative using level order
function maxDepthIterative(root) {
    if (!root) return 0;
    
    let depth = 0;
    const queue = [root];
    
    while (queue.length > 0) {
        const levelSize = queue.length;
        depth++;
        
        for (let i = 0; i < levelSize; i++) {
            const node = queue.shift();
            if (node.left) queue.push(node.left);
            if (node.right) queue.push(node.right);
        }
    }
    
    return depth;
}

Why both versions work

  • The recursive solution computes the height by taking the max depth of the left and right subtrees plus one for the current node.
  • The iterative version performs a level-order traversal, incrementing depth after processing each layer.
  • Both visit every node exactly once, keeping runtime linear.
  • The choice between them comes down to style and whether you want to avoid recursion.
Time: O(n) | Space: O(h) where h is height

2. Validate Binary Search Tree Medium

Determine if a binary tree is a valid BST. 

function isValidBST(root, min = -Infinity, max = Infinity) {
    if (!root) return true;
    
    // Current value must be within range
    if (root.val <= min || root.val >= max) {
        return false;
    }
    
    // Left subtree: all values < root.val
    // Right subtree: all values > root.val
    return isValidBST(root.left, min, root.val) &&
           isValidBST(root.right, root.val, max);
}

Maintaining the valid range

  • Each node must fall strictly between min and max; the root starts with (-∞, ∞).
  • For the left child we clamp max to root.val, and for the right child we clamp min.
  • If any node violates the allowed range, we immediately return false.
  • This enforces the BST rule for all descendants, not just direct children.
Time: O(n) | Space: O(h)

3. Lowest Common Ancestor Medium

Find the lowest common ancestor of two nodes in a BST. 

function lowestCommonAncestor(root, p, q) {
    // If both values are less than root, LCA is in left subtree
    if (p.val < root.val && q.val < root.val) {
        return lowestCommonAncestor(root.left, p, q);
    }
    
    // If both values are greater than root, LCA is in right subtree
    if (p.val > root.val && q.val > root.val) {
        return lowestCommonAncestor(root.right, p, q);
    }
    
    // Otherwise, root is the LCA
    return root;
}

Leveraging BST ordering

  • If both targets are less than the current node, the LCA must sit entirely in the left subtree.
  • If both are greater, we recur into the right subtree.
  • The first node where the values diverge (one on each side, or one equal to the root) is the lowest common ancestor.
  • This avoids storing paths and works in O(h) time.
Time: O(h) | Space: O(h)

📚 Key Takeaways

  • BST provides O(log n) average time for search, insert, delete
  • Three main DFS traversals: inorder, preorder, postorder
  • BFS (level-order) uses a queue for traversal
  • Recursion is natural for tree problems
  • Inorder traversal of BST gives sorted order
