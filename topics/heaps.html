⛰️ Heaps

Efficient priority queue implementation

What is a Heap?

A heap is a specialized tree-based data structure that satisfies the heap property. In a max heap, parent nodes are always greater than or equal to children. In a min heap, parents are always smaller.

Min Heap Implementation

class MinHeap {
    constructor() {
        this.heap = [];
    }
    
    insert(val) {
        this.heap.push(val);
        this.bubbleUp(this.heap.length - 1);
    }
    
    extractMin() {
        if (this.heap.length === 0) return null;
        if (this.heap.length === 1) return this.heap.pop();
        
        const min = this.heap[0];
        this.heap[0] = this.heap.pop();
        this.bubbleDown(0);
        return min;
    }
    
    bubbleUp(index) {
        while (index > 0) {
            const parentIndex = Math.floor((index - 1) / 2);
            if (this.heap[parentIndex] <= this.heap[index]) break;
            
            [this.heap[parentIndex], this.heap[index]] = 
            [this.heap[index], this.heap[parentIndex]];
            index = parentIndex;
        }
    }
    
    bubbleDown(index) {
        while (true) {
            let smallest = index;
            const left = 2 * index + 1;
            const right = 2 * index + 2;
            
            if (left < this.heap.length && 
                this.heap[left] < this.heap[smallest]) {
                smallest = left;
            }
            
            if (right < this.heap.length && 
                this.heap[right] < this.heap[smallest]) {
                smallest = right;
            }
            
            if (smallest === index) break;
            
            [this.heap[index], this.heap[smallest]] = 
            [this.heap[smallest], this.heap[index]];
            index = smallest;
        }
    }
    
    peek() {
        return this.heap[0];
    }
}

Heap mechanics

  • The heap lives in an array so parents/children can be computed with index math.
  • insert appends the value and bubbleUp restores the min-heap property by swapping toward the root.
  • extractMin swaps the root with the last element, pops it, and bubbleDown pushes the new root to its proper place.
  • peek gives O(1) access to the smallest value without restructuring the heap.

💻 Practice Problems

1. Kth Largest Element Medium

Find the kth largest element in an unsorted array using a min heap. 

function findKthLargest(nums, k) {
    const minHeap = new MinHeap();
    
    for (let num of nums) {
        minHeap.insert(num);
        if (minHeap.size() > k) {
            minHeap.extractMin();
        }
    }
    
    return minHeap.peek();
}

Idea in plain English

  • We maintain a min heap of size at most k that stores the largest numbers seen so far.
  • Whenever the heap grows beyond k, we eject the smallest element—ensuring only the top k remain.
  • After processing the array, the heap root is the kth largest because exactly k values are bigger or equal.
  • This beats sorting the entire array (O(n log n)) when k is much smaller than n.
Time: O(n log k) | Space: O(k)

2. Merge K Sorted Lists Hard

Merge k sorted linked lists using a min heap. 

function mergeKLists(lists) {
    const minHeap = new MinHeap((a, b) => a.val - b.val);
    
    // Add first node of each list to heap
    for (let list of lists) {
        if (list) minHeap.insert(list);
    }
    
    const dummy = new ListNode(0);
    let current = dummy;
    
    while (minHeap.size() > 0) {
        const node = minHeap.extractMin();
        current.next = node;
        current = current.next;
        
        if (node.next) {
            minHeap.insert(node.next);
        }
    }
    
    return dummy.next;
}

Why the heap helps

  • The heap always exposes the smallest current node among the k list heads.
  • After we append that node to the output list, we push its successor (if any) back into the heap.
  • This maintains at most k items in the heap, so every extraction takes O(log k).
  • The dummy head simplifies returning the merged list without special cases.
Time: O(n log k) | Space: O(k)

📚 Key Takeaways

  • Heaps provide O(log n) insert and extract operations
  • Perfect for implementing priority queues
  • Min heap keeps smallest element at root, max heap keeps largest
  • Array representation: parent at i, children at 2i+1 and 2i+2
  • Used in algorithms like Dijkstra's and heap sort
