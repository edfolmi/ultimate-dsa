🔗 Linked Lists

Dynamic data structure with efficient insertions and deletions

What is a Linked List?

A linked list is a linear data structure where elements (nodes) are not stored in contiguous memory locations. Each node contains data and a reference (pointer) to the next node in the sequence.

Types of Linked Lists

Singly Linked List

Each node points to the next node only

Doubly Linked List

Each node has pointers to both next and previous nodes

Circular Linked List

Last node points back to the first node

Time Complexity

Access: O(n)
Search: O(n)
Insert (at head): O(1)
Delete (at head): O(1)

Node Structure & Basic Operations

// Node class
class ListNode {
    constructor(val) {
        this.val = val;
        this.next = null;
    }
}

// LinkedList class
class LinkedList {
    constructor() {
        this.head = null;
        this.size = 0;
    }
    
    // Add node at beginning
    addFirst(val) {
        const newNode = new ListNode(val);
        newNode.next = this.head;
        this.head = newNode;
        this.size++;
    }
    
    // Add node at end
    addLast(val) {
        const newNode = new ListNode(val);
        if (!this.head) {
            this.head = newNode;
        } else {
            let current = this.head;
            while (current.next) {
                current = current.next;
            }
            current.next = newNode;
        }
        this.size++;
    }
    
    // Remove first node
    removeFirst() {
        if (!this.head) return null;
        const removed = this.head.val;
        this.head = this.head.next;
        this.size--;
        return removed;
    }
    
    // Print list
    print() {
        let current = this.head;
        const values = [];
        while (current) {
            values.push(current.val);
            current = current.next;
        }
        return values.join(' -> ');
    }
}

How to read this class

  • ListNode stores the payload and pointer, mirroring the textbook definition.
  • addFirst updates head in O(1) by prepending the new node.
  • addLast traverses until current.next is null, then appends the node to the tail.
  • removeFirst simply shifts the head pointer forward and returns the removed value.
  • print walks the list collecting values, which is useful for debugging and visualization.

💻 Practice Problems

1. Reverse Linked List Easy

Given the head of a singly linked list, reverse the list and return the reversed list.

Example:
Input: 1 -> 2 -> 3 -> 4 -> 5
Output: 5 -> 4 -> 3 -> 2 -> 1

Solution (Iterative):

/**
 * Reverse Linked List - Iterative Approach
 * @param {ListNode} head - Head of the linked list
 * @return {ListNode} - Head of reversed list
 */
function reverseList(head) {
    let prev = null;
    let current = head;
    
    while (current !== null) {
        // Save next node
        const nextTemp = current.next;
        
        // Reverse the link
        current.next = prev;
        
        // Move pointers forward
        prev = current;
        current = nextTemp;
    }
    
    // prev is now the new head
    return prev;
}

// Test the function
const list = createList([1, 2, 3, 4, 5]);
const reversed = reverseList(list);
printList(reversed); // 5 -> 4 -> 3 -> 2 -> 1

Solution (Recursive):

/**
 * Reverse Linked List - Recursive Approach
 * @param {ListNode} head - Head of the linked list
 * @return {ListNode} - Head of reversed list
 */
function reverseListRecursive(head) {
    // Base case: empty list or single node
    if (head === null || head.next === null) {
        return head;
    }
    
    // Recursively reverse the rest of the list
    const newHead = reverseListRecursive(head.next);
    
    // Reverse the link between current and next node
    head.next.next = head;
    head.next = null;
    
    return newHead;
}

Explanation:

Iterative:
1. Keep track of previous, current, and next nodes
2. Reverse the link by pointing current.next to prev
3. Move all pointers one step forward
4. Continue until current becomes null

Recursive:
1. Recursively reverse the list starting from the second node
2. Reverse the link between current and next node
3. Set current.next to null (now it's the tail)
4. Return the new head

Time Complexity: O(n) - Visit each node once
Space Complexity: O(1) iterative, O(n) recursive (call stack)

2. Linked List Cycle (Floyd's Algorithm) Easy

Given head of a linked list, determine if the linked list has a cycle in it.

Example:
Input: 3 -> 2 -> 0 -> -4 (where -4 points back to node with value 2)
Output: true (there is a cycle)

Solution:

/**
 * Detect Cycle - Floyd's Tortoise and Hare Algorithm
 * @param {ListNode} head - Head of the linked list
 * @return {boolean} - True if cycle exists, false otherwise
 */
function hasCycle(head) {
    // Handle empty list or single node
    if (head === null || head.next === null) {
        return false;
    }
    
    // Initialize slow and fast pointers
    let slow = head;
    let fast = head;
    
    // Move slow by 1, fast by 2
    while (fast !== null && fast.next !== null) {
        slow = slow.next;
        fast = fast.next.next;
        
        // If they meet, there's a cycle
        if (slow === fast) {
            return true;
        }
    }
    
    // Fast reached end, no cycle
    return false;
}

/**
 * Find the start of the cycle (bonus!)
 * @param {ListNode} head
 * @return {ListNode} - Node where cycle begins, or null
 */
function detectCycle(head) {
    if (head === null || head.next === null) {
        return null;
    }
    
    let slow = head;
    let fast = head;
    let hasCycle = false;
    
    // Detect cycle
    while (fast !== null && fast.next !== null) {
        slow = slow.next;
        fast = fast.next.next;
        
        if (slow === fast) {
            hasCycle = true;
            break;
        }
    }
    
    if (!hasCycle) return null;
    
    // Find cycle start: reset slow to head
    slow = head;
    while (slow !== fast) {
        slow = slow.next;
        fast = fast.next;
    }
    
    return slow; // The cycle start node
}

Explanation:

Floyd's Cycle Detection Algorithm (Tortoise and Hare):
1. Use two pointers: slow (moves 1 step) and fast (moves 2 steps)
2. If there's a cycle, fast will eventually catch up to slow
3. If fast reaches null, there's no cycle

Why it works: In a cycle, the faster pointer will lap the slower one. The relative speed is 1 node per iteration, so they must meet.

Time Complexity: O(n) - At most 2n iterations
Space Complexity: O(1) - Only two pointers

3. Merge Two Sorted Lists Easy

Merge two sorted linked lists and return it as a sorted list.

Example:
Input: list1 = 1->2->4, list2 = 1->3->4
Output: 1->1->2->3->4->4

Solution:

/**
 * Merge Two Sorted Lists
 * @param {ListNode} list1 - Head of first sorted list
 * @param {ListNode} list2 - Head of second sorted list
 * @return {ListNode} - Head of merged sorted list
 */
function mergeTwoLists(list1, list2) {
    // Create a dummy node to simplify logic
    const dummy = new ListNode(0);
    let current = dummy;
    
    // Traverse both lists
    while (list1 !== null && list2 !== null) {
        if (list1.val <= list2.val) {
            current.next = list1;
            list1 = list1.next;
        } else {
            current.next = list2;
            list2 = list2.next;
        }
        current = current.next;
    }
    
    // Attach remaining nodes
    if (list1 !== null) {
        current.next = list1;
    }
    if (list2 !== null) {
        current.next = list2;
    }
    
    return dummy.next;
}

// Recursive solution
function mergeTwoListsRecursive(list1, list2) {
    // Base cases
    if (list1 === null) return list2;
    if (list2 === null) return list1;
    
    // Choose smaller node and recursively merge rest
    if (list1.val <= list2.val) {
        list1.next = mergeTwoListsRecursive(list1.next, list2);
        return list1;
    } else {
        list2.next = mergeTwoListsRecursive(list1, list2.next);
        return list2;
    }
}

Explanation:

Iterative:
1. Use a dummy node to simplify edge cases
2. Compare values from both lists and attach smaller node
3. Move pointer in the list from which node was taken
4. Attach remaining nodes when one list is exhausted

Recursive:
1. Base cases: if one list is null, return the other
2. Choose the smaller head and recursively merge remaining lists
3. Return the smaller head

Time Complexity: O(n + m) - Visit all nodes once
Space Complexity: O(1) iterative, O(n + m) recursive

📚 Key Takeaways

  • Linked lists excel at insertions/deletions but are slower for random access
  • Floyd's cycle detection (slow/fast pointers) is a common pattern
  • Dummy nodes simplify linked list manipulation code
  • Many linked list problems can be solved both iteratively and recursively
  • Two-pointer technique is powerful for linked list problems
  • Always check for null pointers to avoid errors
