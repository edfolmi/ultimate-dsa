📦 Arrays

Master the most fundamental data structure

What is an Array?

An array is a collection of elements stored in contiguous memory locations. It's one of the most basic and widely used data structures in programming. Arrays allow you to store multiple values of the same type under a single variable name.

Key Characteristics

  • Fixed or Dynamic Size: In JavaScript, arrays are dynamic and can grow/shrink
  • Index-Based Access: Access elements in O(1) time using indices (0-based)
  • Contiguous Memory: Elements stored sequentially in memory
  • Homogeneous/Heterogeneous: JS arrays can store mixed types

Time Complexity

Access: O(1)
Search: O(n)
Insert: O(n)
Delete: O(n)

Common Operations

// Creating an array
const arr = [1, 2, 3, 4, 5];

// Accessing elements
console.log(arr[0]); // 1

// Modifying elements
arr[0] = 10; // [10, 2, 3, 4, 5]

// Adding elements
arr.push(6);        // Add to end: [10, 2, 3, 4, 5, 6]
arr.unshift(0);     // Add to start: [0, 10, 2, 3, 4, 5, 6]

// Removing elements
arr.pop();          // Remove from end
arr.shift();        // Remove from start

// Array methods
arr.length;         // Get array length
arr.slice(1, 3);    // Get subarray
arr.splice(1, 2);   // Remove/insert elements
arr.indexOf(3);     // Find element index
arr.includes(5);    // Check if element exists

How to interpret these snippets

  • The first block shows the fundamental CRUD actions (create, read, update, delete) you use constantly.
  • push/pop mutate the tail, whereas unshift/shift work at the head and cost O(n).
  • Slice/splice demonstrate non-destructive vs. destructive ways to carve out portions of an array.
  • Helpers like indexOf and includes enable searches when you do not want to write loops manually.

💻 Practice Problems

1. Two Sum Easy

Given an array of integers nums and an integer target, return indices of the two numbers that add up to target.

Example:
Input: nums = [2, 7, 11, 15], target = 9
Output: [0, 1] (because nums[0] + nums[1] = 2 + 7 = 9)

Solution:

/**
 * Two Sum - Using Hash Map for O(n) solution
 * @param {number[]} nums - Array of integers
 * @param {number} target - Target sum
 * @return {number[]} - Indices of two numbers
 */
function twoSum(nums, target) {
    // Create a hash map to store number and its index
    const map = new Map();
    
    // Iterate through the array
    for (let i = 0; i < nums.length; i++) {
        // Calculate the complement (what we need to find)
        const complement = target - nums[i];
        
        // If complement exists in map, we found the pair
        if (map.has(complement)) {
            return [map.get(complement), i];
        }
        
        // Store current number and its index
        map.set(nums[i], i);
    }
    
    // No solution found
    return [];
}

// Test the function
console.log(twoSum([2, 7, 11, 15], 9)); // [0, 1]
console.log(twoSum([3, 2, 4], 6));       // [1, 2]
console.log(twoSum([3, 3], 6));          // [0, 1]

Explanation:

1. We use a hash map to store each number and its index as we iterate
2. For each number, we calculate its complement (target - current number)
3. If the complement exists in our map, we've found the pair
4. Otherwise, we add the current number to the map and continue

Time Complexity: O(n) - Single pass through array
Space Complexity: O(n) - Hash map storage

2. Maximum Subarray (Kadane's Algorithm) Medium

Find the contiguous subarray with the largest sum within an array of integers.

Example:
Input: [-2, 1, -3, 4, -1, 2, 1, -5, 4]
Output: 6 (subarray [4, -1, 2, 1] has the largest sum)

Solution:

/**
 * Maximum Subarray - Kadane's Algorithm
 * @param {number[]} nums - Array of integers
 * @return {number} - Maximum sum of contiguous subarray
 */
function maxSubArray(nums) {
    // Initialize with first element
    let maxSum = nums[0];
    let currentSum = nums[0];
    
    // Iterate from second element
    for (let i = 1; i < nums.length; i++) {
        // Either extend existing subarray or start new one
        currentSum = Math.max(nums[i], currentSum + nums[i]);
        
        // Update maximum sum if current is larger
        maxSum = Math.max(maxSum, currentSum);
    }
    
    return maxSum;
}

// Test the function
console.log(maxSubArray([-2, 1, -3, 4, -1, 2, 1, -5, 4])); // 6
console.log(maxSubArray([1]));                               // 1
console.log(maxSubArray([5, 4, -1, 7, 8]));                 // 23

Explanation:

Kadane's Algorithm is a dynamic programming approach:
1. Keep track of current sum and maximum sum
2. At each position, decide: extend current subarray or start new one
3. If adding current element to existing sum is worse than the element alone, start fresh
4. Update maximum sum whenever current sum is larger

Time Complexity: O(n) - Single pass
Space Complexity: O(1) - Constant space

3. Rotate Array Medium

Rotate an array to the right by k steps, where k is non-negative.

Example:
Input: nums = [1, 2, 3, 4, 5, 6, 7], k = 3
Output: [5, 6, 7, 1, 2, 3, 4]

Solution:

/**
 * Rotate Array - Using Reversal Algorithm
 * @param {number[]} nums - Array to rotate
 * @param {number} k - Number of steps to rotate
 */
function rotate(nums, k) {
    k = k % nums.length; // Handle k > array length
    
    // Helper function to reverse array portion
    function reverse(arr, start, end) {
        while (start < end) {
            [arr[start], arr[end]] = [arr[end], arr[start]];
            start++;
            end--;
        }
    }
    
    // Three reversals to achieve rotation:
    // 1. Reverse entire array
    reverse(nums, 0, nums.length - 1);
    // 2. Reverse first k elements
    reverse(nums, 0, k - 1);
    // 3. Reverse remaining elements
    reverse(nums, k, nums.length - 1);
    
    return nums;
}

// Test the function
console.log(rotate([1, 2, 3, 4, 5, 6, 7], 3)); // [5, 6, 7, 1, 2, 3, 4]
console.log(rotate([-1, -100, 3, 99], 2));      // [3, 99, -1, -100]

Explanation:

The reversal algorithm is clever and efficient:
1. First reverse the entire array
2. Then reverse the first k elements
3. Finally reverse the remaining n-k elements
This achieves rotation with O(1) extra space!

Time Complexity: O(n) - Each reversal is O(n)
Space Complexity: O(1) - In-place rotation

📚 Key Takeaways

  • Arrays provide O(1) access time but O(n) insertion/deletion (except at end)
  • Use hash maps with arrays for O(n) solutions to pair-finding problems
  • Kadane's algorithm is the go-to for maximum subarray problems
  • Two-pointer technique is powerful for array problems
  • Consider in-place algorithms to optimize space complexity
