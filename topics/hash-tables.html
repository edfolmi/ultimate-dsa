🗂️ Hash Tables

Fast key-value lookups with O(1) average time

What is a Hash Table?

A hash table (also called hash map) is a data structure that maps keys to values using a hash function. It provides very fast lookups, insertions, and deletions - typically O(1) on average.

How it Works

  1. Hash Function: Converts key to an index in the array
  2. Storage: Value is stored at the computed index
  3. Collision Handling: Resolves when two keys hash to same index

Collision Resolution Techniques

Chaining

Each bucket stores a linked list of entries

Open Addressing

Find next open slot (linear probing, quadratic probing)

Time Complexity

Search: O(1) average, O(n) worst
Insert: O(1) average, O(n) worst
Delete: O(1) average, O(n) worst

Implementation

// Hash Table with chaining
class HashTable {
    constructor(size = 50) {
        this.buckets = new Array(size);
        this.size = size;
    }
    
    // Hash function
    hash(key) {
        let hash = 0;
        for (let i = 0; i < key.length; i++) {
            hash = (hash + key.charCodeAt(i) * i) % this.size;
        }
        return hash;
    }
    
    // Insert key-value pair
    set(key, value) {
        const index = this.hash(key);
        
        if (!this.buckets[index]) {
            this.buckets[index] = [];
        }
        
        // Check if key exists, update if found
        const bucket = this.buckets[index];
        for (let i = 0; i < bucket.length; i++) {
            if (bucket[i][0] === key) {
                bucket[i][1] = value;
                return;
            }
        }
        
        // Add new entry
        bucket.push([key, value]);
    }
    
    // Get value by key
    get(key) {
        const index = this.hash(key);
        const bucket = this.buckets[index];
        
        if (!bucket) return undefined;
        
        for (let i = 0; i < bucket.length; i++) {
            if (bucket[i][0] === key) {
                return bucket[i][1];
            }
        }
        
        return undefined;
    }
    
    // Delete key-value pair
    delete(key) {
        const index = this.hash(key);
        const bucket = this.buckets[index];
        
        if (!bucket) return false;
        
        for (let i = 0; i < bucket.length; i++) {
            if (bucket[i][0] === key) {
                bucket.splice(i, 1);
                return true;
            }
        }
        
        return false;
    }
    
    // Check if key exists
    has(key) {
        return this.get(key) !== undefined;
    }
}

Why this implementation works

  • The custom hash function spreads keys across size buckets to minimize collisions.
  • Each bucket stores a small array so chaining can handle multiple keys that hash to the same index.
  • set first checks for the key to avoid duplicates before pushing a new pair.
  • get, delete, and has all reuse the hash function, so every operation stays O(1) on average.

💻 Practice Problems

1. Group Anagrams Medium

Given an array of strings, group anagrams together.

Example:
Input: ["eat","tea","tan","ate","nat","bat"]
Output: [["bat"],["nat","tan"],["ate","eat","tea"]] 

function groupAnagrams(strs) {
    const map = new Map();
    
    for (let str of strs) {
        // Sort string to create key
        const key = str.split('').sort().join('');
        
        if (!map.has(key)) {
            map.set(key, []);
        }
        
        map.get(key).push(str);
    }
    
    return Array.from(map.values());
}

console.log(groupAnagrams(["eat","tea","tan","ate","nat","bat"]));

Breaking down the idea

  • Sorting the letters is the canonical representation of an anagram group.
  • That sorted string becomes the map key, so words that share characters land in the same bucket.
  • We lazily create each bucket (array) to keep memory usage tight.
  • Returning the map values gives us an array of grouped anagrams with no extra processing.
Time Complexity: O(n * k log k) where k is max string length

2. Longest Consecutive Sequence Medium

Find the length of the longest consecutive elements sequence in an unsorted array. 

function longestConsecutive(nums) {
    if (nums.length === 0) return 0;
    
    const set = new Set(nums);
    let maxLength = 0;
    
    for (let num of set) {
        // Only start counting if it's the beginning of a sequence
        if (!set.has(num - 1)) {
            let currentNum = num;
            let currentLength = 1;
            
            while (set.has(currentNum + 1)) {
                currentNum++;
                currentLength++;
            }
            
            maxLength = Math.max(maxLength, currentLength);
        }
    }
    
    return maxLength;
}

console.log(longestConsecutive([100,4,200,1,3,2])); // 4

Key insights

  • The set lets us check for membership in O(1), which is crucial for staying linear time.
  • We only start counting when num - 1 is missing; that guarantees each sequence is processed once.
  • The inner while walks forward through the consecutive numbers, tallying the streak length.
  • Tracking maxLength through the loop avoids storing intermediate sequences.
Time Complexity: O(n)

📚 Key Takeaways

  • Hash tables provide O(1) average-case lookups, insertions, and deletions
  • Good hash functions distribute keys uniformly to minimize collisions
  • Use hash tables for counting, grouping, and detecting duplicates
  • JavaScript's Map and Set are built on hash table principles
  • Hash tables trade space for time - excellent for optimization
