Working with bits efficiently

Bitwise Operations

// Basic operations
const AND = 5 & 3;    // 0101 & 0011 = 0001 (1)
const OR = 5 | 3;     // 0101 | 0011 = 0111 (7)
const XOR = 5 ^ 3;    // 0101 ^ 0011 = 0110 (6)
const NOT = ~5;       // ~0101 = 1010 (-6 in 2's complement)
const LEFT = 5 << 1;  // 0101 << 1 = 1010 (10)
const RIGHT = 5 >> 1; // 0101 >> 1 = 0010 (2)

// Common tricks
function isPowerOfTwo(n) {
    return n > 0 && (n & (n - 1)) === 0;
}

function countSetBits(n) {
    let count = 0;
    while (n > 0) {
        count += n & 1;
        n >>= 1;
    }
    return count;
}

function getBit(n, i) {
    return (n >> i) & 1;
}

function setBit(n, i) {
    return n | (1 << i);
}

function clearBit(n, i) {
    return n & ~(1 << i);
}

function toggleBit(n, i) {
    return n ^ (1 << i);
}

Reading these samples

  • The first six lines demonstrate how each bitwise operator transforms the binary representation.
  • isPowerOfTwo leverages the fact that powers of two have exactly one set bit, so n & (n-1) becomes zero only for those numbers.
  • The helper functions (getBit, setBit, etc.) show how shifts and masks isolate or update a specific position.
  • These patterns compose into most competitive-programming style bit tricks.

💻 Practice Problems

1. Single Number Easy

Find the number that appears once (all others appear twice).

function singleNumber(nums) {
    let result = 0;
    for (let num of nums) {
        result ^= num; // XOR cancels out duplicates
    }
    return result;
}

Why XOR solves it

  • XOR-ing a number with itself yields zero, so duplicate entries cancel out bit-by-bit.
  • Zero XOR x equals x, so the lone number survives all cancellations.
  • We can fold through the array in O(1) space because the intermediate XOR is all we need.
  • No sorting or hash maps are required, keeping runtime linear.

2. Number of 1 Bits Easy

function hammingWeight(n) {
    let count = 0;
    while (n !== 0) {
        n &= (n - 1); // Removes rightmost 1
        count++;
    }
    return count;
}

Step-by-step logic

  • The expression n &= (n - 1) knocks out the lowest set bit in each iteration.
  • Counting how many times we can perform that operation equals the number of 1s.
  • This is faster than checking every bit individually because it loops only over set bits.
  • The loop ends when n becomes zero, meaning all bits were cleared.

📚 Key Takeaways

  • XOR useful for finding unique elements
  • n & (n-1) removes rightmost set bit
  • Bit operations are very fast
  • Used in cryptography, compression, graphics
